# Como contribuir

O Vibeproof fica melhor quando alguém aponta uma lacuna, encontra uma explicação mais clara ou percebe que uma orientação mudou. Obrigado por ajudar!

## Sugerir uma melhoria

Abra uma [issue](https://github.com/thiagojspereira/Vibeproof/issues/new) com o guia e o trecho em questão. Conte qual problema você encontrou, em que situação ele importa e, se possível, inclua uma fonte oficial atual. Para ideias de novos guias, explique que tarefa prática eles ajudariam a executar ou revisar.

## Enviar uma alteração

1. Faça um fork e crie uma branch para a sua mudança.
2. Altere apenas o necessário, em português claro, com passos que possam ser aplicados ou verificados.
3. Indique quando um item depende do tipo de projeto e evite apresentar recomendações como obrigações universais.
4. Confira links, exemplos, fontes e dados que possam ser sensíveis; não inclua credenciais nem dados reais de usuários.
5. Abra um pull request explicando o problema, a solução e como você a verificou.

Ao contribuir, você concorda que seu conteúdo original seja disponibilizado sob a [licença CC BY 4.0](LICENSE). Não envie textos ou imagens de terceiros sem permissão compatível; mantenha a atribuição das fontes.
